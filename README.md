# Ransomware Detection
Ransomware is a type of malicious software that encrypts user files and demands payment for access restoration. It has become one of the most disruptive forms of cyber-attacks, particularly affecting data-reliant organizations, users, and stakeholders who depend on secure, uninterrupted access to their files and services. Cyber-attacks on healthcare systems, for example, have caused disruptions in critical services, delays in patient care, and compromise of sensitive data. A recent case in October 2025 saw two hospitals in Massachusetts declare a “Code Black” following a ransomware attack that halted essential operations. Since the COVID-19 pandemic, cyber-attacks have doubled, underscoring the growing threat of ransomware in today’s interconnected world.

Traditional ransomware detection techniques rely on static code analysis, which examines program instructions or API calls but is easily evaded by obfuscation and is impractical for Network Attached Storage systems where code inspection is limited. Instead, this project focuses on dynamic analysis of filesystem activity, taking advantage of the distinctive read and write behaviors produced by ransomware. The goal is to build an intelligent agent that dynamically detects ransomware activity from filesystem traffic data in real time. The system leverages machine learning models to distinguish malicious from benign processes while maintaining data privacy and minimizing reliance on large datasets through reinforcement learning. It aims to achieve high accuracy and strong recall, even when encountering new or unseen ransomware strains.

Using the RanSMAP dataset, one hundred and four temporal, entropy-based, and address-pattern features were extracted through a rolling-window preprocessing pipeline. Exploratory analysis revealed clear behavioral differences between benign and malicious processes, including elevated entropy, irregular address jumps, and distinctive MMIO activity. Dimensionality reduction with t-SNE and PCA further confirmed separability between the two classes.

To assess detection capability, Support Vector Machines, Feed-Forward Neural Networks, Long Short-Term Memory networks, and a one-dimensional Convolutional Neural Network were trained and evaluated across thirty-six unseen ransomware and benign application pairs.
While all models performed excellently on seen data, their accuracy on unseen families ranged from 60\% to 70\%. TranAD, a transformer-based anomaly detector trained exclusively on benign behavior, outperformed the others on unseen data, achieving the highest recall and yielding the best overall performance across all ransomware variants.


These findings show that dynamic behavioral telemetry provides meaningful signals for ransomware detection but also demonstrate the challenge of generalizing to new ransomware variants. This will require adaptive models, improved temporal representations, and techniques such as transformer architectures and reinforcement learning to better handle evolving ransomware behaviors.
