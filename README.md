# Ransomware Detection
Ransomware is a type of malicious software that encrypts user files and demands payment to restore access. Many current detection methods depend on static code analysis, which is often ineffective because ransomware hides or alters its code. This challenge is especially significant in Network Attached Storage systems, where files are accessed remotely and direct code inspection is not possible. To address this limitation, this project explores detecting ransomware through its behavior rather than its code, focusing on patterns in filesystem activity that can be monitored dynamically.
The goal is to build an intelligent agent that identifies ransomware in real time using machine learning. Following ideas from Sarewap and colleagues on dynamic file system traffic analysis, the project extracts behavioral features such as file creation, deletion, modification frequency, and entropy of modified files. The RanSMAP Ransomware Behavioral Features Dataset is used, containing six gigabytes of storage and memory access logs from six benign and six ransomware processes. Features were generated over time windows to capture changes in read, write, and memory access patterns.
Dimensionality reduction techniques (t-SNE, PCA, UMAP) were used to visualize behavioral clusters, which showed clear separation between benign and malicious activity. Machine learning models, including a decision tree, support vector machine, and a feed-forward neural network, were trained and tested. When evaluated on unseen data, such as WannaCry and Firefox, the neural network achieved strong performance, confirming that ransomware exhibits distinct and detectable behavioral patterns.
These findings suggest that dynamic filesystem monitoring is a practical and privacy-aware approach for detecting ransomware in real time and could form the basis for future intelligent defense systems.
