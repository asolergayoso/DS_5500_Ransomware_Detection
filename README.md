# Ransomware Detection
This project seeks to address the growing challenge of detecting ransomware activity in real time while minimizing reliance on large, sensitive datasets. Current detection methods often require extensive amounts of labeled data, which can be difficult to obtain in enterprise settings and raise privacy concerns when collected from users. The goal of this work is to design a data-efficient, privacy-conscious detection agent that identifies ransomware behavior dynamically from filesystem traffic. By focusing on early behavioral signals such as access frequency, file modifications, entropy changes, and size fluctuations, the system aims to deliver a lightweight yet effective defense against ransomware attacks.

To achieve this, the proposed solution will leverage deep reinforcement learning, specifically Proximal Policy Optimization, to train an agent capable of distinguishing between benign and malicious file activity through episodic interactions. The detection workflow combines multiple classification approaches Support Vector Machines and Decision Trees for speed and interpretability, alongside Deep Neural Networks for capturing complex patterns. This hybrid design balances performance with practicality, enabling a system that can adapt to evolving ransomware behaviors while maintaining real-world deployability. By grounding the approach in publicly available behavioral datasets of ransomware families and carefully structuring the reinforcement learning framework, the project aims to deliver a scalable, resilient tool for enhancing ransomware defense in modern storage environments.
