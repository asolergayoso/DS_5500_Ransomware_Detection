# Ransomware Detection
This project aims to design a dynamic ransomware detection system using deep reinforcement learning to monitor filesystem traffic in real time. Unlike existing approaches that require large, often inaccessible datasets, our solution focuses on privacy-preserving methods that minimize the need for extensive training data. By leveraging reinforcement learning, the system will learn to detect ransomware behavior through episodic interactions, using filesystem features such as access frequency, modification timestamps, size changes, and entropy levels. The detection agent will operate within a defined action space, ALERT or NO_ALERT,  and employ Proximal Policy Optimization to optimize decision-making.

To balance accuracy, speed, and interpretability, the classification layer integrates Support Vector Machines, Decision Trees, and Deep Neural Networks. This hybrid approach allows the system to quickly identify interpretable ransomware indicators while capturing more complex behavioral patterns. Motivated by the real-world challenge of protecting NAS devices while respecting user privacy, this project seeks to create an adaptable, data efficient ransomware defense mechanism. The key challenge lies in designing a reinforcement learning framework that realistically simulates ransomware behavior and trains the agent effectively without compromising scalability or reliability.
